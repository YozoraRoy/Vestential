## 命名哲學

**Accumulation Arc — 累積弧。**

Vestential = Vest + Essential。它的視覺 DNA 是一個「低谷」：一條流暢的弧線自左上沉入圓潤的谷底，
再以更高的姿態升起於右上——左手是下跌的耐心，右手是昇華的回收。低谷不是挫敗，而是價值投資者靜默的進場區。

弧以品牌藍（`#4f8cff`）流入品牌綠（`#34d399`）：從「等待」漸變為「成長」。弧右端的綠色圓點是唯一的重點標記——
它同時是目標價、是一次辨識完成的鐘點、也是這個系統裡唯一一個需要出聲的音符。

餘下留白。像線圖上方的天空，讓弧本身就是全部敘事。

## 設計決定

- **形**：立方貝茲畫出的單一連續弧（valley-V），兩端圓帽漸細（尖端 42px → 谷底 62px）。
- **色**：沿弧長由 `#4f8cff` → `#34d399` 無縫漸變；右端目標點為綠 `#34d399`。
- **細節**：谷底上方一條極淡的水平虛線——「支撐位」，讓圖像帶有線圖/涵蓋隱喻，但不喧賓奪主。
- **字**：Bahnschrift（DIN 系幾何 sans）、全大寫、寬字距；與弧的工程感一致。
- **執行**：Python + PIL，6× 超採樣 + LANCZOS 降採樣，確保邊緣乾淨無鋸齒。
